# Brahim Hoggas — Demonstration Portfolio

A responsive, framework-free portfolio mockup built with HTML, CSS, and JavaScript. The four projects, timeline project milestones, and statistics are fictional demonstration content; they are not claims about real experience or achievements.

## Run locally

Open index.html directly, or start a static server from this folder:

~~~sh
python -m http.server 8000
~~~

Then visit http://localhost:8000.

## Customize

- Update the biography and education details in index.html.
- Edit technologies, demo statistics, project names, descriptions, and timeline entries in index.html.
- Replace social # links only when real profile URLs are available. Project repository and demo buttons stay disabled until genuine URLs are supplied.
- The contact form uses example@example.com as a demo email. Change contactEmail in script.js and the displayed address in index.html together.
- Adjust theme colors, spacing, and responsive breakpoints in styles.css.

The BH logo is inline SVG. The profile illustration and project thumbnails are CSS art; there are no external image or logo dependencies.
